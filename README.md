# 音声シャッターカメラ (tooth-check-app)

シャッターボタンを押さずに、音声だけで写真を撮影できるカメラアプリです。
ビルド不要のプレーンな HTML / CSS / JavaScript で作られています。

## 使い方

1. 「カメラを起動」を押してカメラへのアクセスを許可する(撮影モードになります)。
2. 「音声操作を開始」を押してマイクへのアクセスを許可する。
3. 撮影モード中に話しかけると、内容に応じて撮影します。
   - **「フラッシュオン」** と言う → フラッシュ(トーチ)を点灯してから撮影し、自動で消灯します。
   - **「オン」** と言う → フラッシュなしでそのまま撮影します。
4. 撮影した写真は画面下のギャラリーに一覧表示されます(タップして保存できます)。
5. 音声が使えない環境では「📷 撮影」「🔦 フラッシュ」ボタンで手動操作もできます。

## 動作環境について

- **カメラ (getUserMedia)**: HTTPS または `localhost` などのセキュアコンテキストが必要です。
- **音声認識 (Web Speech API)**: 現状 Chrome (Android / デスクトップ) など一部のブラウザのみ対応しています。
  対応していないブラウザでは自動的に警告が表示され、手動ボタンのみ利用できます。
- **フラッシュ(トーチ)制御**: 背面カメラにトーチ機能がある Android 端末の Chrome など、一部の環境でのみ動作します。
  対応していない端末では、「フラッシュオン」と言った場合もフラッシュなしで撮影のみ行われます。

## ローカルでの動作確認

セキュアコンテキストが必要なため、単純に `index.html` を `file://` で開くのではなく、簡易サーバー経由で開いてください。

```bash
# 例1: Python
python3 -m http.server 8000

# 例2: Node.js (npx)
npx serve .
```

ブラウザで `http://localhost:8000` を開いて動作確認できます。
スマートフォン実機で確認する場合は、GitHub Pages や Vercel などの HTTPS ホスティングにデプロイしてください。
